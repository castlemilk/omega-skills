# Visual review rubric

Inspect actual pixels before reading the title or interpreting the premise. Use **strong**, **mixed**, **weak** or **not tested**, with one concrete observation. Do not invent numerical beauty scores.

| Criterion | Useful evidence |
| --- | --- |
| Brief fit | Dark restraint, clear contours and the requested mode survive without relying on effects. |
| Silhouette | A coherent gesture with purposeful mass, openings and terminals. |
| Formal clarity | The specified separation, connection, nesting, cut or shared edge is visible. |
| Human reading | The whole, part relationship and distinctive detail form a plausible hierarchy; competing gaps or contour treatments are identified. Treat this as visual judgment unless tested with viewers. |
| Family relationship | The new construction is distinguishable while retaining the chosen principles; refinement preserves the selected identity. |
| Narrative usefulness | A visible relationship supports the stated interpretation. |
| Presentation consistency | Type, scale, layout and material treatment allow a meaningful comparison. |
| Practical performance | Use actual application evidence; otherwise mark small-size performance, vector equality and fabrication as not tested. |
| Learned preference fit | Identify the active preference and supporting user feedback IDs; distinguish an explicit constraint from a hypothesis. |
| Useful comparison | The variation tests one uncertainty while its baseline and presentation remain interpretable. |

## Inspection sequence

1. Count disconnected filled components.
2. Distinguish enclosed voids from openings connected to the exterior.
3. Trace each important recess, blind end and bridge.
4. Examine outer contour, terminal shape, section weight and gap hierarchy.
5. Compare the observed change with the parent and stated experiment.
6. Check exact wordmark spelling and main/miniature correspondence.
7. Inspect neighbouring contours for collateral changes after an edit.
8. Record a decision and the smallest useful next comparison.

When material or chrome studies are included, compare their topology and openings with the flat emblem. A successful material treatment does not establish faithful geometry.

## Decision language

- **Retain:** useful construction or comparison.
- **Refine:** promising direction with a specific weakness.
- **Park:** informative but lower priority for the active objective.
- **Explore further:** distinct relationship with a worthwhile unresolved question.

These are assistant judgments unless the user explicitly selects a result. Keep different reviewers' scopes clear.

## Review after user selections

Follow [numbered curation and learning](selection-learning.md). Resolve the exact displayed revisions before interpreting feedback. Inspect selected images and any stated comparisons; save a preference without visual inference if its image cannot be accessed.

Separate four questions: what the user chose, what reason the user stated, what the image visibly contains, and what the assistant hypothesises. A common feature among favourites suggests a comparison to run; it does not prove the user's reason. Unselected images provide no negative rating.

Carry a prior selected image as a baseline when judging a refinement. Keep framing, type, material and scale comparable when testing geometry. An assistant rating can identify a visible change, but only subsequent user feedback can establish that the change better matches that user's taste.

Evaluate a new lesson against supporting and contrary selection events across distinct batches. Reduce or retire an inference when evidence conflicts, and re-evaluate lessons that depend on undone feedback. Avoid counting repeated views, corrections or retries as independent preference evidence. Keep a credible alternative in adaptive mode so the process can discover an over-narrow assumption.

## Common diagnoses

| Observation | Useful response |
| --- | --- |
| New image repeats its parent | Change one observable relationship or reduce the parent's influence in a new construction brief. |
| Intended nesting becomes adjacency | Name the surrounding sides and required clearance. |
| A bridge joins the wrong region | Specify the exact joining endpoint and the opening that must remain. |
| Repetition or alignment fails | Identify each unit's direction or the precise edges meant to align. |
| Wider gaps weaken the whole | Compare an intermediate clearance while preserving the component shapes. |
| Miniature changes topology | Correct that rendition before claiming correspondence. |
| Editing one feature changes another | Record the collateral change and judge the actual result. |
| A mark resembles a familiar object or letter | Describe the association as a reading and compare whether it helps the intended identity. |

Do not claim exact symmetry, mathematical equality, global originality or improved recognition from a concept board alone. Measured raster geometry can support a dimensional observation; it is not a recognition study. Stop optional generation once the requested batch and justified corrections are complete.
